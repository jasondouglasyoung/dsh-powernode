## 启动与复现

Alpha.4 当前已运行，可在本机浏览器打开 `本机服务地址（未公开）`。停止当前实例后，可在仓库根目录运行：

```powershell
powershell.exe -NoLogo -NoProfile -File .\scripts\start-dsh-dev.ps1 `
  -DshHome "<本机用户目录> `
  -Profile workflow-ui-alpha4 `
  -Port 3084
```

隔离安装命令：

```powershell
powershell.exe -NoLogo -NoProfile -File .\scripts\install-alpha-profile.ps1 `
  -Tarball artifacts\dsh-workflow-plugin-0.1.0-alpha.4.tgz `
  -Profile workflow-ui-alpha4 `
  -DshHome "<本机用户目录>
```

启动脚本会隐藏 DSH URL 中的本机访问 token；报告不记录 token 或任何密钥值。
