# 演示需求：中文产品介绍页

请制作一个简单的中文静态页面，介绍一款专注学习的桌面计时工具。

## 页面内容

- 页面标题：专注时段
- 一段简短介绍，说明它帮助学生安排专注和休息时间。
- 三张功能卡片：专注计时、休息提醒、学习记录。每张卡片包含标题和一句说明。
- 页面底部有一句鼓励开始学习的文案。

## 交付产物

- 在指定输出目录生成 index.html 和 style.css。
- HTML 使用语义化结构；CSS 独立保存，不内嵌到 HTML。
- 使用简体中文，不依赖外部图片、字体服务、CDN 或 JavaScript。

## 检查要求

- 在桌面浏览器中打开 index.html 可直接看到完整页面。
- 在 360 px 宽的手机视口中不出现横向滚动，标题、介绍和三张卡片仍易读。
- 三张卡片样式一致，页面层级与留白遵守 style-guide.md。
